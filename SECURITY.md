# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Cue Chrome Palette**, please **do not** open a public GitHub issue.

Instead, report it privately using GitHub's **Private Vulnerability Reporting**:

1. Go to the repository's **Security** tab.
2. Click **Advisories** -> **Report a vulnerability**.
3. Include a description of the issue, steps to reproduce, and any relevant details.

We will review reports as quickly as possible and coordinate a fix before public disclosure.
